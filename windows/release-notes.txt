Windows 桌面迁移到 Electron：控制中心、设备编辑、手机翻页、屏幕共享选择、远控、外网连接和更新窗口改用 HTML/CSS，沿用原有布局和交互。
保留原剪贴板、热键、认证、广播、发现、远控及更新后台；安装时沿用已有设备列表和设置，关闭终端后继续独立运行。
手机侧边栏语音输入：使用手机麦克风，通过电脑豆包输入法转文字；支持 Windows 豆包 0.9.1.22、0.9.2.7，电脑需有 Steam Streaming Microphone 或 VB-CABLE 虚拟声卡。
新增版本更新提醒，可查看更新内容并下载 Windows 安装包。
手机连接电脑支持局域网自动发现，首次核对确认标识并在电脑允许一次；配对持久保存，IP 变化后自动重新发现，无需手填 IP 或 PIN。
新增 Windows 电脑之间的实时屏幕共享，直接共享整个主屏幕。
屏幕共享页面沿用控制中心的深色界面。
新增手机全屏预览翻页控制，可在电脑上切换上一页、下一页。
新增手机远控：安装包内置远程桌面引擎，在 ClipRelay 中开启并完成 PIN 配对后，手机即可查看和操作电脑桌面。
新增手机授权管理、断开连接、后台服务自动启动与故障恢复。
新增内置外网连接：手机和电脑只安装 ClipRelay，无需独立 Tailscale 软件或账号。
电脑生成八位配对码，核对手机标识并允许后即可建立外网通道；支持撤销授权、自动恢复、直连与服务器中转。
手机触控模式点击可编辑输入框后自动弹出手机键盘；电脑仅发送输入焦点状态，不读取输入内容。
新增前台应用识别：手机可自动切换星露谷、速速上菜、Orca 和 ChatGPT 操作模式；仅发送预设应用标识，不读取窗口标题。
修复 Orca 手机触控滑动无反应，单指滑动改用滚轮兼容，并保留手动模式选择。
新增手机图片传到电脑剪贴板：从远控工具栏选择图片并确认后传输，支持透明 PNG；沿用配对加密通道，返回串流后可手动粘贴。
修复检测链路时无法自动更新设备地址：地址去重只校验启用中的设备，停用的旧设备不再占用地址导致整批保存失败；地址冲突报错会同时指出两台设备名称。
控制中心检测结果详情放不下时自动折成两行，完整错误不再被面板截断。

01 / 现状

一屏 13 个框，没有主角

现在的控制中心由旧 WinForms 布局逐像素导出，字号、间距和绝对坐标都沿用了旧窗口。主要问题在信息密度和层级，配色只是次要因素。

  1. 面板过多一屏 13 个带边框的面板，每个都有自己的标题，视线找不到落点。
  2. 英文小标题只是装饰NETWORK STATS、TARGET NODES、SHORTCUTS、PREFERENCES 重复了下面的中文，还占着最醒目的位置。
  3. 字号偏小正文 12px，说明 10.67px，需要换行的说明被压到 7.5pt。缩放到 125% 仍然吃力。
  4. 同一件事说三遍广播目标等于设备数，在线状态等于检测结果，旧版接收的状态在侧栏出现三次。
  5. 主次颠倒最大的实心按钮是诊断用的「检测全链路连接」；首次使用最需要的「添加设备」只有 62×24。
  6. 绝对定位留下错位空状态写死在 top:48px；长错误详情把行高撑到 32px，盖住相邻标签。

02 / 结构

主窗口只留三件事

同步状态、设备列表、一个页脚。其余内容按「跟谁有关」重新分配：设备相关的进设备菜单，全局的进设置，偶尔用的进托盘。

状态先行

第一行永远是同步状态，一个圆点加一句话。打开窗口就能判断是否正常。

常驻操作只有四个

添加设备、单台开关、全部暂停、设置。检测连接放进设备菜单，打开窗口时自动跑一次。

次要功能跟着对象走

手机翻页只对安卓设备出现；屏幕共享只在共享进行时出现一条横幅。

中文标题，不加英文眉题

分组标题只写「设备」「常规」「兼容性」。英文小标题不再承担装饰作用。

现在的元素处理去向
品牌区 + 「设备链路工作区」大标题删除标题栏只保留标记和 ClipRelay
NETWORK STATS 统计卡删除设备数并入「设备」标题，最近同步并入状态行
TARGET NODES 设备列表保留主窗口唯一的列表
SHORTCUTS 快捷键卡降级设置 › 快捷键
LAST ACTIVITY 活动卡合并状态行下面一行「最近 12:31 …」
PREFERENCES 偏好卡移出设置 › 常规 / 这台电脑 / 兼容性
「检测全链路连接」大按钮降级打开时自动检测；设备菜单「重新检测」
「手机翻页」顶栏按钮下沉安卓设备菜单
「远程桌面」顶栏按钮降级页脚入口，托盘保留一份
屏幕共享状态面板条件显示共享进行时的顶部横幅
自动保存状态文字删除保存失败时才提示
版本更新按钮降级页脚版本号，点开是更新窗口

05 / 落地

改哪些文件，动哪些测试

改动集中在渲染层，桥接协议和配置格式都不变。第一轮只做控制中心与设置页，其余窗口下一轮统一。

窗口与文件

  • windows.cjs：control-center 改为 [520, 520]，设置视图切到 [520, 720]，允许纵向拉伸，最小 520 × 460。
  • 新增 renderer/views/control-center.js，手写结构；app.js 不再 fetch 布局 JSON。
  • 删除 layouts/control-center.json 与 export-electron-layout.ps1 的导出步骤，windows-files.json 同步移除。
  • bridge.ps1、preload.js、native-host.cjs 不动，patch / probe / discover / merge / summary / copy 的语义不变。

交互映射

  • 设备开关：patch({peers, expectedRevision})，与现在一致。
  • 全部暂停 / 恢复：一次 patch 把全部 enabled 置为同一值，后端不需要新字段。
  • 添加设备：现有 peer-editor；设备菜单：现有 peer-menu，增加「重新检测」「手机翻页」。
  • 状态行：由 runtime、probe 结果和 sharing.Stage 组合，不再单独维护检测文案。
  • 设置页：输入框失焦、开关点击即保存，沿用现有 patch。
  • 设备超过 4 台时在卡片内滚动，最多 16 台；最近一条同步记录固定在列表下方。

其余窗口（下一轮）

  • 远程桌面与外网配对是整窗浅色的 WinForms 风格；远程桌面首页、更新和共享选择器是深色且各自硬编码颜色。
  • 先抽按钮、输入框、列表、开关、提示条五个组件，再逐窗替换，并让所有窗口跟随系统深浅色。
  • 托盘菜单同步去表情符号，改成纯文字加勾选状态。

需要你拍板

四个会影响实现的问题

  • 远程桌面入口放哪建议：页脚

    放主窗口页脚最容易被找到，也不会挤占状态区；托盘里保留一份，重度用户可以从托盘直接进。

  • 是否接受「全部暂停」建议：保留

    用现有设备开关组合实现，一次 patch 写全部 enabled，后端不改。暂停时逐台开关的旧值不会记住，恢复时全部打开。

  • 浅色主题是否跟随系统

    本稿给了完整的浅色映射。实现需要额外一轮对比度验收，Windows 的强调色、标题栏和托盘菜单也要一起处理。

  • 设置页放在同窗口还是独立窗口

    同窗口切换的体验更连贯，代价是切换视图时要调整窗口高度。独立窗口更简单，但会多一个右上角关闭按钮和一层焦点管理。

ANDROID / FILE TRANSFER / 02
文件传输 · 设计提案

文件有条理，传输有方向。

浏览电脑文件，发送和下载各有入口；传输进度随时可见。

01浏览与发送手机 → 电脑

列表留给文件。目录层级清楚，发送按钮固定在底部，明确保存到电脑的哪个文件夹。

02选择与下载电脑 → 手机

选中后再出现下载操作。文件数量和总大小就近呈现，下一步选择手机保存位置。

03传输任务进度 · 暂停 · 继续

进度收进底部面板。每项任务标明传输方向，暂停、继续和取消都能直接操作。
